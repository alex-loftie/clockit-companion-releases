# CLOCK:IT Companion — Releases

Installers for CLOCK:IT Companion, the desktop companion app for the CLOCK:IT MK1.

This repo holds built release binaries only. There's no source code here — it lives in a
private repo — this exists purely so download links work for people who aren't on that
repo's access list.

## Downloads

Grab the installer for your platform from the [Releases page](../../releases/latest):

- **macOS** — `.dmg`, one universal build for Intel and Apple Silicon
- **Windows** — `.exe` installer
- **Linux** — `.deb` or `.AppImage`

## First run

These builds are currently unsigned, so your OS will flag them on first launch:

- **macOS** — Gatekeeper blocks it outright. Right-click the app, choose **Open**, then
  **Open** again to confirm. Only needed once per machine.
- **Windows** — SmartScreen shows a warning. Choose **More info → Run anyway**.
- **Linux** — installs normally, nothing to confirm.
